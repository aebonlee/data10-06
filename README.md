# data10-06 · 설비고장 원인 및 진단파악(AI)

증상을 넣으면 과거 정비 사례에서 가능한 고장 원인과 「먼저 확인할 것」을 짚어 주고, 쌓인 정비 사례로 초보자용 자체 정비 가이드북과 외부 수리 비용 현황을 만드는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 유상진 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 2차 반영 (2026-10-21) — 실제 설비 고장 수리이력 양식을 그대로 읽기 · 「자료 점검」 화면 — https://aebonlee.github.io/data10-06/ |
| 다음 개발 | 2단계 — 실제 정비 내역서로 사례집 만들기, 설비 매뉴얼 근거 질의(RAG), 팀 공유 저장소 |

> 과제는 패들릿으로 접수했고, 2차에 2025~2026 설비 고장 수리이력(60건)을 받았습니다. 원본·설비 이름·업체 이름·금액은 리포에 넣지 않았고, 같은 모양의 가상 표로 시험합니다. 샘플(설비 A~E 정비 사례 30건, 가상 수리이력 26건)은 모두 지어낸 값입니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-06/**

처음 열면 「① 증상 진단」 화면입니다. **「예시 데이터로 시작」** 을 누르면 가상 설비 5대·정비 사례 30건이 들어갑니다. 예시 버튼 「온도가 안 올라가고 기계가 멈춤」 을 누르면 히터 단선·온도 센서 불량이 위로 나오고, 센서 쪽은 「센서 커넥터 연결 상태 확인」 부터 보라고 짚어 줍니다.
실제로 쓸 때는 외부 정비 내역서를 엑셀로 옮겨 「내역서 가져오기」 로 넣거나, 「정비 사례 → 사례 등록」 으로 한 건씩 넣습니다. 데이터는 서버로 보내지 않고 이 브라우저 안에만 저장합니다(사례는 localStorage, 사진은 줄인 사본을 IndexedDB).

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

| 화면 | 하는 일 |
|---|---|
| ① 증상 진단 | 설비·증상 문장·증상 태그(글에서 자동으로 켜짐) → 비슷한 과거 사례(한국어 글자 2개 묶음 TF-IDF + 같은 태그 + 같은 설비 가산점) → 가능 원인 순위·비중·근거 사례 수·「먼저 확인할 것」(사례의 첫 확인 단계), **과거 사례 기반 추정** 표시. 증상 + 사례 + 매뉴얼 발췌를 묶은 AI 프롬프트(복사 → 붙여 넣기, 선택: 설정한 AI 서버로 자동 보내기), 고친 뒤 새 사례로 등록 |
| ② 정비 사례 | 설비·일시·증상·태그·원인·조치 단계·교체 부품·필요 공구·외부/자체·비용·소요시간·사진(긴 변 1280px 로 줄여 한 건 10장까지, 돌리기·순서·빼기)·영상 위치·비고. 거르기, 엑셀 내보내기, 빈 양식, 저장 공간 경고 |
| ③ 자체 정비 가이드북 | 원인별 카드 자동 초안 — 이런 증상일 때 · 안전 먼저(전원 차단·잠금 LOTO 표준 문구 + 전기·고온·유압·회전체) · 확인 순서(「초보자는 여기까지」 선 · 담당자·전문가 단계 표시) · 필요 공구·자주 바꾼 부품 · 멈추고 전문가를 부를 때. 고치기(고친 칸만 저장)·초안으로 되돌리기·카드별/전체 인쇄·글 복사·AI 로 다듬기 |
| ④ 비용 현황 | 기간 · 외부 수리 비용·건수·자체 처리 비율·외부 1건 평균, 앞/뒤 기간 비교, 월별 그래프 3개, 월별·설비별·원인별 표, 자체 처리 전환 후보, 엑셀·인쇄 |
| 내역서 가져오기 | 엑셀(여러 시트 · 같은 모양 시트 함께 · 병합 셀) · 머리행 자동 찾기 · 열 맞추기(연결 저장) · **원인 칸이 없으면 증상·조치에서 짐작(「짐작」 표시)** · 처리일자/비고에서 조치 · 「2025-03 2주차」 일자 · 비용 미기재/무상/개당/견적 · 업체 → 외부/자체 · 처리 상태 · 못 읽은 값 줄 번호 알림 · 같은 건 건너뛰기 |
| 자료 점검 | 「이렇게 올리면 되나요?」 — 칸별 채움률·왜 필요한가, 기능별 상태, 더 채우면 좋은 칸, 중복 의심·진행 중·견적 줄, 설비 종류·부위, 권장 양식 받기·내 자료를 권장 양식으로 내보내기 |
| 설정 | 설비 목록(종류·모델·제조사·매뉴얼 메모), 진단 기준값, AI 연결(OpenAI 호환 주소·모델·본인 키, 기억은 선택), 백업(JSON, 사진 포함)·되살리기, 예시·모두 지우기 |
| 다음 단계 | 보내 주실 자료 체크 목록, 2단계 순서 |

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 고장 원인 진단 챗봇 | 완료(규칙 + 반자동 AI) | 과거 사례로 원인 순위·먼저 확인할 것을 계산하고, AI 는 그 사례·매뉴얼 발췌만 근거로 답하게 프롬프트를 만듦. 대화형 챗봇·매뉴얼 근거 질의는 2단계 |
| 초보자용 자체 정비 가이드북 | 완료(자동 초안 + 수정) | 사례가 쌓일수록 원인별 카드가 자람. 전기·유압·고온 작업은 초보자가 멈추는 선을 표시. 사내 작업 허용 범위는 확인 후(기획서 10장 6번) |
| 정비 내역서·영수증 | 완료(엑셀) · 2차 실제 양식 | 수리이력 엑셀을 그대로 읽음(기획서 11장). 종이·PDF 에서 항목 뽑기는 2단계 |
| 고장 사진·동영상 | 사진 완료 | 사진은 줄인 사본을 사례에 붙임. 동영상은 위치만. 사진 폴더를 파일 이름으로 한꺼번에 붙이기는 2단계 |
| 외부 수리 비용 줄이기 | 완료(현황) | 월별 비용·자체 처리 비율 변화, 자체 처리 전환 후보 |
| 팀 공유 | 2단계 | 지금은 브라우저별 저장 + JSON 백업 |
